# 🤖 AI Chatbot with Context Memory (Free)

A Streamlit-based AI chatbot that **remembers previous conversations** and can answer **domain-specific queries** (student queries, e-commerce product info, or tech FAQs) using Hugging Face models — **no OpenAI API key required**.

---

## 🚀 Features

- **Contextual Memory:** Remembers previous messages in the chat session using `ConversationBufferMemory`.  
- **Free to Run:** Uses Hugging Face models locally; no OpenAI key needed.  
- **Domain-Specific Queries:** Can answer questions about student courses, product details, or technical FAQs.  
- **Easy UI:** Built with Streamlit for a clean and interactive chat interface.  
- **Extendable:** Can be integrated with PDFs or documents for retrieval-augmented responses.

---

## 🛠️ Tech Stack

- **Python**  
- **LangChain** (`langchain-community`)  
- **Hugging Face Transformers**  
- **Streamlit** (UI)  
- **FAISS (optional)** for long-term memory
